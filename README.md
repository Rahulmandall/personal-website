## 🌐 How to Preview in Your Browser

1. **Option A (Instant)**: Simply double-click `index.html` to open it in your default web browser (Chrome, Edge, Firefox, Brave).
2. **Option B (VS Code Live Server)**:
   - Install the **Live Server** extension by Ritwick Dey in VS Code.
   - Right-click `index.html` and choose **"Open with Live Server"** (or press `Alt + L, Alt + O`).
   - Your site will open at `http://127.0.0.1:5500/index.html` with instant live reload upon saving.

## 🛠️ How to Add Future Projects

In `index.html`, locate the `<section id="projects">` element. You'll find a commented project template:

```html
<article class="project-card">
  <div class="project-top">
    <div class="project-badge-row">
      <div class="project-icon-box">
        <!-- Any SVG Icon or image -->
      </div>
      <span class="project-type-tag">Category (e.g. Full-Stack / React)</span>
    </div>
    <h3 class="project-title">Project Name</h3>
    <p class="project-desc">
      A concise description of what the project does and its features.
    </p>
    <div class="project-tech-stack">
      <span class="tech-badge">React</span>
      <span class="tech-badge">Node.js</span>
      <span class="tech-badge">MongoDB</span>
    </div>
  </div>
  <div class="project-footer">
    <a href="https://github.com/RahulMandall/your-repo" target="_blank" rel="noopener noreferrer" class="project-link">
      <span>View on GitHub</span>
    </a>
  </div>
</article>
```
Simply copy and paste that block inside `.projects-grid` to display a new project!
